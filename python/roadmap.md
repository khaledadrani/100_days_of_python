| Level                                   | Target audience / prerequisites                                                   | Core topics & skills                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | Sample projects / assessments                                                                                                                                                                                                                                                                                                                                                                   |
| --------------------------------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Beginner**                            | Someone who’s new or with minimal coding exposure                                 | - Python setup, REPL, interpreter vs script <br> - Variables, basic types (int, float, bool, str) <br> - Basic control flow: `if`, `for`, `while`, `break/continue` <br> - Collections: list, tuple, dict, set <br> - Basic input/output, file reading/writing <br> - Functions (args, return) <br> - Basic error handling (`try/except`) <br> - Introduction to modules and packages <br> - Simple testing (asserts)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | * A command-line quiz program <br> * Parsing a simple CSV file and summarizing data <br> * Small “calculator” script <br> * Write small functions and test them                                                                                                                                                                                                                                 |
| **Standard / Core Python**              | After beginner, comfortable writing small programs                                | - More on functions: default args, `*args` / `**kwargs`, keyword-only args <br> - Comprehensions, generator expressions <br> - Iterators & generators (including `.send()`, `yield from`) <br> - Decorators (function decorators, decorator arguments) <br> - Context managers & `with` statement <br> - Modules, `__init__.py`, package structure, relative vs absolute imports <br> - Logging, `argparse` / CLI tools <br> - More refined error/exception design, custom exceptions <br> - Introduction to standard library modules (e.g. `collections`, `itertools`, `functools`, `math`, `datetime`) <br> - Virtual environments, packaging basics (`setuptools`, `pip`) <br> - Testing: `unittest`, `pytest` basics <br> - Type hinting, `mypy` basics                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | * Build a CLI tool (e.g. file organizer, simple backup script) <br> * Write a small library (with modules) <br> * Write unit tests for existing code <br> * Type-annotate a small project and check with `mypy`                                                                                                                                                                                 |
| **Intermediate**                        | Students who’ve built some scripts/libraries and want to scale up                 | - Object-oriented design deeper: multiple inheritance, abstract base classes (`abc`), mixins <br> - Advanced data models: `__slots__`, `__str__`, `__repr__`, **eq**/**hash**/**lt** etc <br> - Dunder / magic methods, operator overloading <br> - Metaclasses (basic introduction) <br> - Descriptors, properties <br> - Advanced decorators (class decorators, decorator patterns) <br> - Context managers advanced, resource management <br> - Concurrency / parallelism: `threading`, `multiprocessing`, `asyncio` <br> - Async programming: `async` / `await`, `asyncio.Queue`, `asyncio.gather`, cancellation, event loop <br> - Coroutines, asynchronous iterators/generators <br> - More on typing: generics, `Protocol`, `TypeVar`, `ParamSpec`, `Literal` etc <br> - Performance & profiling: `cProfile`, `timeit`, memory profiling <br> - Design patterns in Python (Singleton, Observer, Strategy, Factory etc) <br> - Packaging more seriously: building wheels, distribution, versioning <br> - Deployment basics: Dockerization, continuous integration, packaging for production <br> - More on testing: mocks, fixtures, property-based testing (Hypothesis)                                                                                                                                                                                  | * Build a small web microservice (Flask / FastAPI) with async endpoints <br> * Create a plugin or extension architecture using metaclasses or registration patterns <br> * Write a data processing pipeline (async) <br> * Benchmark and optimize code <br> * Prepare a package and publish to a private PyPI <br> * Use CI/CD (GitHub Actions, etc) <br> * Testing with `pytest`, `hypothesis` |
| **Advanced**                            | For those who want mastery, deeper internals, high scale                          | - Deep dive into Python internals: memory model, garbage collector, reference counting, cyclic GC <br> - Bytecode (dis module), CPython internals, interpreter loop <br> - C-API / CPython extension development (writing modules in C) <br> - Alternative Python implementations (PyPy, Jython, etc) <br> - GIL (Global Interpreter Lock), its consequences, and how to mitigate <br> - Metaprogramming at scale: custom class creation, dynamic class generation <br> - AST manipulation, code generation, using `ast` and `compile` <br> - Just-in-time compilation tools (e.g. Numba) <br> - Concurrency models: event-driven systems, advanced asyncio (loop internals, custom event loops), trio/curio <br> - Multiprocessing in depth, cluster computing, distributed task queues (Celery, Dask) <br> - Memory management & optimization (buffer protocols, contiguous memory, `ctypes`, `struct`) <br> - Profiling and tracing (e.g. `line_profiler`, `py-spy`, `tracemalloc`) <br> - Advanced packaging & dependency management (PEP 517/518, isolations, tox, poetry, pipenv, version constraints) <br> - Security in Python: sandboxing, code injection, introspection risks <br> - Interfacing with other languages (C, Rust via FFI, Cython) <br> - Reflection, dynamic imports, plugin systems <br> - code obfuscation, code signing, distribution | * Build a small CPython extension in C <br> * Write a domain-specific language (DSL) using AST transforms <br> * Create an event-driven server with custom event loops <br> * Build a mini JIT or optimizer <br> * Contribute to or read CPython source <br> * Build a complex plugin architecture with dynamic loading <br> * Perform profiling and optimization on a real system              |
| **Expert / Research / Innovator level** | For people pushing boundaries, building frameworks, contributing to Python itself | - In-depth contribution to CPython or other interpreters <br> - Proposing / understanding PEPs, language design <br> - Writing compilers / transpilers <br> - Programs that embed Python (embedding API) <br> - Advanced toolchains (static analysis, linters, language servers) <br> - Formal verification, static typing research (e.g. MyPy plugin internals, Pyright) <br> - Metaprogramming for domain-specific tools (e.g. ORM internals, hyper-optimizing frameworks) <br> - Language-level optimizations, new garbage collector ideas, exotic concurrency models <br> - Interoperability across languages and runtimes (embedding, bridging)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | * Contribute code / review in CPython <br> * Implement a language extension / PEP <br> * Build your own mini-interpreter or transpiler <br> * Write a static analyzer or linter <br> * Research a performance improvement or novel feature <br> * Publish your findings, present talks                                                                                                          |
